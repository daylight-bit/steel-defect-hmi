# 界面如何承接检测任务

已有 CameraWorker 通过信号发送帧数据、状态和错误；ReconstructionWorker 保存输入图像及缺陷实例的副本，并在开始任务前检查图像和掩码。

这些实现提示了两个交互原则：耗时工作与界面刷新分离；任务应绑定启动时的样本，不能随着页面选择变化而悄悄更换对象。

可以进一步验证：任务运行中切换样本、连续点击启动、输入空掩码、设备读取失败时，界面是否给出明确状态。上述检查尚未在本次实际运行。

阅读开源组件时，应记录来源和许可证、输入输出、项目适配点及验证结果。第三方结构光代码的存在只证明代码包包含该依赖，不能证明由个人原创或已经完成真实硬件移植。
